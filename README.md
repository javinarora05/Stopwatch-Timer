# ⏱️ Stopwatch Timer

> A browser stopwatch built to practice timing, state updates and DOM events.

## ✨ Features
- Start / stop / reset controls
- Elapsed-time display
- Timestamp logging
- Clear log history
- Vanilla JavaScript
